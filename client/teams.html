Kurulum

5 Dakikada
Çalışır

1
Repoyu klonla

GitHub'dan projeyi çek, .env dosyasını kopyala.

2
Gizli anahtarları ayarla

JWT_SECRET ve REFRESH_SECRET doldur. Opsiyonel: AI API key'i ekle.

3
Docker'ı başlat

Tek komutla tüm servisler (Bridge, PostgreSQL, Redis) ayağa kalkar.

4
İlk kayıt = Admin

Uygulamaya ilk kaydolan kullanıcı otomatik admin yetkisi alır.

Terminal
# 1. Klonla
git clone https://github.com/bridge-app/bridge
cd bridge

# 2. Ortam değişkenlerini ayarla
cp .env.docker .env
# JWT_SECRET ve REFRESH_SECRET doldur

# Opsiyonel: AI (ikisi de ücretsiz plan sunar)
GROQ_API_KEY=gsk_xxxx
GEMINI_API_KEY=AIzaxxxx

# 3. Başlat
docker compose up -d

# → http://localhost:3001 ✓
